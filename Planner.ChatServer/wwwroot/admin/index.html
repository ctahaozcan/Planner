Yaver yönetim

Şirket, kadro, davet, izin yetkisi ve denetim. Boş kadroyu kimse kendi seçemez; davet kodu veya e-posta kilidi ile oturtulur.

HTTPS / üretim.

Yerel HTTPS kapı 47883 (kendinden imzalı). Üretimde Nginx/Caddy reverse proxy ile gerçek sertifika kullanın; Kestrel’i loopback’te bırakın. İlk girişten sonra varsayılan yönetici şifresini değiştirin (en az 12 karakter).

# nginx örneği
server {
  listen 443 ssl;
  server_name yaver.firma.com;
  ssl_certificate     /etc/ssl/certs/yaver.pem;
  ssl_certificate_key /etc/ssl/private/yaver.key;
  location / {
    proxy_pass http://127.0.0.1:47880;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto https;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    client_max_body_size 25m;
  }
}

Giriş

İlk kurulumda şifre appsettings.json → Admin:Password (eski varsayılan: YaverAdmin). Hash veritabanında saklanır; panelden güçlü şifreye geçin.

Yönetici şifresini değiştirin

Hâlâ varsayılan veya zayıf şifre. Üretimde reverse proxy + güçlü şifre şart.
